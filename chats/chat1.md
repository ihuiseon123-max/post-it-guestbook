# 오리엔테이션 익명 포스트잇 보드

_Started 2026-09-15 13:17 UTC_

---

## User

Design a mobile app for 오리엔테이션에서 사용하는 '익명 디지털 포스트잇 방명록' 웹사이트를 디자인해줘.

목적:
- 오리엔테이션 참가자들이 회원가입 없이 접속
- 짧은 인삿말을 작성
- 작성한 내용이 포스트잇 형태로 화면에 붙음
- 다른 참가자들이 남긴 인삿말도 실시간으로 볼 수 있음

사용자 흐름:
1. QR코드로 사이트 접속
2. 메인 화면에서 다른 사람들의 포스트잇 확인
3. '+ 포스트잇 붙이기' 버튼 클릭
4. 닉네임 또는 익명 입력
5. 인삿말 작성
6. 포스트잇 색상 선택
7. '붙이기' 클릭
8. 보드에 포스트잇이 추가됨

디자인 방향:
- 대학생/취준생 대상 오리엔테이션
- 밝고 친근하며 재미있는 분위기
- 실제 포스트잇을 벽에 붙인 느낌
- 너무 아동스럽지 않게
- 모바일에서 사용하기 편하게
- PC 화면에서는 여러 포스트잇이 벽처럼 배치
- 포스트잇이 약간씩 회전되어 자연스럽게 배치
- 포스트잇 색상은 여러 가지 제공
- 작성 완료 시 포스트잇이 살짝 나타나는 애니메이션

필요한 화면:
1. 메인 포스트잇 보드
2. 포스트잇 작성 모달
3. 작성 완료 상태
4. 포스트잇이 없는 초기 상태

먼저 UI 디자인을 만들어줘.
